## How to use this document

For each case study, the published metrics must trace to real evidence. If a
metric cannot be confirmed from the sources listed below, it must be revised to
qualitative wording or removed — never replaced with another invented number.

Status legend:

- **Owner-asserted** — the metric was provided by the owner in project briefs and
  is treated as fact pending documentary evidence.
- **Requires confirmation** — no documentary evidence is currently attached; the
  owner must confirm or the metric must be revised/removed.
- **Revised (qualitative)** — an unverifiable exact figure was replaced with
  qualitative wording on [date]. Re-publish only if real evidence is attached.

## Recommended evidence vault (private)

Suggested location: a private folder (e.g. Google Drive or the project's private
admin) containing, per case study:

1. Upwork contract reference / invoice
2. Original client requirement (brief or message)
3. Delivery file (redacted spreadsheet or field-layout screenshot)
4. Any client-approved testimonial
5. Verification notes (how emails/roles were checked)

Attach the evidence reference next to each row above as it is gathered. Once a
row has evidence, move it to **Owner-asserted with evidence** and consider
restoring exact figures (only the figures the evidence supports).

## Rules for publication

- Do **not** publish: client names without permission, real contact data,
  screenshots of client files without permission, or metrics not in this table.
- Prefer fewer, fully evidenced case studies over many weak ones.
- Any metric restored from evidence must match the delivery file exactly.
