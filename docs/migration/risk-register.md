## Required evidence before final migration map

1. Owner-approved read-only export: every blog (published and draft), every portfolio ID/slug/body/image/results/date, and settings **key inventory** with secret values excluded. Capture export time and source environment privately.
2. Search Console performance/indexing/canonical/sitemap exports and analytics landing-page/conversion exports for a documented period; retain host, protocol and path dimensions.
3. Backlink/referring-page export and historical redirect/404 logs. Unknown coverage is not evidence of no backlinks.
4. DNS/hosting/domain redirect rules, deployment revision and asset manifest; actual existing host redirects may differ from configuration intent.
5. Owner approvals for host choice, WIP acceptance, per-content revisions, sample offer, numerical claims, testimonials and legal scope.

## Cutover acceptance checklist (not executed)

- Every source candidate has a signed-off target, status and rationale; no fabricated DB-only slug/UUID list.
- Stable URLs stay stable; approved moved pages get direct relevant permanent redirects; irrelevant retired pages get deliberate 404/410. Never blanket redirect `/en/*` or `/topics/*` without evidence.
- Public/draft/admin boundaries work in HTML, markdown, feed, sitemap, llms and APIs; no secret settings in public payloads.
- Canonical host is consistent across both hosts/schemes, HTML/OG/schema, feeds/discovery and redirects. Invalid/missing routes are real errors, not homepage soft-404s.
- Forms tested with mocked delivery first; any real delivery test separately authorized. Admin/media/AI tests use nonproduction accounts/data.
- Claims and placeholders resolved; demo records remain explicitly fictional and excluded from markdown.
- Backups, rollback, monitoring, GSC handoff and post-launch comparison are approved. No statement here certifies indexed status.
